Serial ADC Data Visualizer
A real-time data acquisition and visualization tool for embedded systems. This Python application reads analog-to-digital converter (ADC) values from various peripheral devices via a serial port and plots them in dynamic, interactive graphs.

Perfect for: Engineers, students, and hobbyists working with Arduino, ESP32, STM32, and other microcontrollers to visualize sensor data in real-time.
